# CO7093 Coursework – Group 46

## Project Overview
This repository contains the coursework for CO7093 Big Data & Predictive Analytics.

The project analyses the diabetes hospital dataset to:
- explore and clean the data
- visualise important patterns
- build classification models for early readmission prediction
- apply distributed analysis with PySpark
- perform clustering and cluster-based local classification

## Repository Structure
- `data/raw/` – original dataset files
- `data/processed/` – cleaned and transformed datasets created during the project
- `notebooks/` – notebooks for each coursework stage
- `src/` – reusable Python modules and helper functions
- `figures/` – saved plots for the report
- `results/` – saved metrics, tables, and cluster summaries
- `docs/` – working notes and contribution records
- `report/` – report drafting files and references
- `tests/` – basic checks for project robustness
- `submission/` – final packaged submission files

## Current Workflow
1. Raw data audit
2. Cleaning and preprocessing
3. Exploratory data analysis and visualisation
4. Initial model building and imbalance handling
5. PySpark distributed model
6. Clustering analysis
7. Local classifiers by cluster
8. Final report and submission packaging
